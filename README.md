# Resume Analyzer
A fully scalable and end to end web app for a resume analyzer application.

# Step to run the application

```
1. git clone https://github.com/IshaqKHATTAK/resume-analyzer.git
```
```
2. cd backend 
3. pip install -r requirements.txt
4. python -m uvicorn main:app --port 8010  (acces backend on: http://localhost:8010/docs)
```
```
5. cd ../frontend 
6. npm start  (access frontend on http://localhost:3000/)
```
